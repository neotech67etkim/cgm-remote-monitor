# Seller Crawler

쿠팡 WING(판매자센터)과 네이버 스마트스토어센터에 **본인 계정으로 로그인**하여, 정산 예정/입금 일정 등 판매자 관리 페이지의 정보를 주기적으로 읽어와 JSON 파일로 저장하는 도구입니다.

> 본인이 소유/운영하는 판매자 계정에 한해 사용하세요. 각 플랫폼의 이용약관 및 자동화 정책을 확인하고, 과도한 요청으로 서비스에 부담을 주지 않도록 수집 주기를 적절히 설정하세요.

## 동작 방식

1. 캡차/2단계인증 때문에 아이디·비밀번호를 코드에 넣어 완전 자동으로 로그인하는 방식은 신뢰할 수 없습니다. 대신 **최초 1회는 직접 브라우저에서 로그인**하고, 로그인된 세션(쿠키)을 로컬에 저장합니다.
2. 이후 실행부터는 저장된 세션으로 로그인 없이 바로 원하는 페이지에 접속해 데이터를 읽어옵니다.
3. 세션이 만료되면(오래 지나거나 강제 로그아웃되면) 다시 `npm run login:<platform>` 으로 재로그인해야 합니다.

## 설치

```bash
cd tools/seller-crawler
npm install
npx playwright install chromium
cp .env.example .env   # 값 채우기
```

## 1) 최초 로그인 (세션 저장)

```bash
npm run login:coupang
npm run login:naver
```

브라우저 창이 뜨면 직접 로그인(캡차/2단계인증 포함)을 완료한 뒤, 관리자 페이지가 정상적으로 보이는 것을 확인하고 터미널에서 Enter를 누르세요. `.auth/coupang.json`, `.auth/naver.json` 에 세션이 저장됩니다. (이 파일들은 로그인 쿠키를 담고 있으므로 절대 커밋하거나 공유하지 마세요. `.gitignore`에 이미 제외되어 있습니다.)

## 2) 수집할 셀렉터 설정

이 저장소에서는 로그인 후에만 보이는 실제 관리자 페이지의 HTML 구조를 확인할 수 없습니다. `config/selectors.json`을 열어, 크롬 개발자도구(F12)로 실제 정산 페이지의 URL과 CSS 셀렉터를 확인한 뒤 `REPLACE_WITH_...` 부분을 채워 넣으세요.

- `url`: 데이터를 읽어올 페이지 주소
- `waitForSelector`: 페이지 로딩이 끝났다고 판단할 기준 셀렉터 (표가 그려진 뒤 나타나는 요소 등)
- `type: "table"`인 경우 `rowSelector`(행 셀렉터)와 `columns`(열 이름 → 셀 셀렉터)를 지정
- `type`을 생략하면 `fields`(필드 이름 → 셀렉터)로 단일 값들을 추출

필요하면 `pages` 배열에 항목을 더 추가해 여러 페이지(정산 내역, 입금 예정, 매출 요약 등)를 함께 수집할 수 있습니다.

## 3) 1회 실행

```bash
npm run run
```

`data/latest.json`과 `data/result-<timestamp>.json`에 결과가 저장됩니다.

## 4) 주기적 자동 수집

```bash
npm run schedule
```

`.env`의 `SCHEDULE_CRON`(기본값: 매일 오전 9시, `0 9 * * *`)에 따라 자동 실행됩니다. 프로세스가 계속 떠 있어야 하므로 서버나 pm2 등으로 상시 구동하세요.

## 참고

- 사이트 개편으로 셀렉터가 깨질 수 있으니 수집 결과가 비어 있거나 `error` 필드가 있으면 `config/selectors.json`을 다시 점검하세요.
- 세션 저장 파일과 `.env`(로그인 URL 등)는 민감 정보이므로 안전하게 보관하세요.
